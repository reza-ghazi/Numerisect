SHANKS SQUARE FORMS

SQUFOF

Shanks' square forms factorization, for odd inputs below 262. No installed library provides SQUFOF, so Numerisect supplies it as a compiled C program using GMP. An exhausted search is inconclusive and never a claim that the input is prime.

ALGORITHM CROSS-CHECK

            
Count π(x) with independent algorithms

            
primecount ships six independent prime-counting algorithms, and PARI/GP primepi is a seventh implementation that shares no code with them. Running several on one x turns agreement into a correctness check that no single algorithm can give for itself. Any disagreement is reported prominently and never reconciled. Legendre, Meissel and Lehmer are capped at x ≤ 10¹⁶; PARI primepi joins only while x ≤ 10¹¹.

            

              
              
              
              
            

            

              
              
              
              
              
              
            

            
Elapsed times are single measurements of one run on this machine. They are not a benchmark of the algorithms.

FACTORINT STRATEGY MASKS

            
Compare PARI factoring strategies

            
The second argument of factorint is a bitmask of methods to avoid: 1 avoids MPQS, 2 avoids the first-stage ECM, 4 avoids Pollard–Brent rho and Shanks SQUFOF, 8 skips the final ECM. Running one input under several masks is a PARI-side comparison of factoring methods; PARI's gettime measures each run and isprime audits every returned base, which is what exposes what mask 8 gave up.

Solve x² − dy² = 1
